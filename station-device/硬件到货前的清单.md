## 3 第 2 周：录像与人员检测（清单第 3 节）

**全部可以在电脑上完成，不需要树莓派。**

### 3.1 准备录像

- [ ] 录一段**获准使用**的 `test.mp4`，放进 `D:\Projects\station-device\inputs\`
- [ ] 内容至少覆盖三类场景，这决定你能查出多少问题：
  - [ ] 空场 —— 检查是否误报
  - [ ] 少量人员 —— 检查能否稳定检测
  - [ ] 人员交错或短暂遮挡 —— 观察漏检
- [ ] 拍摄时固定机位并记录：相机高度、角度、与人员的距离（**以后复现机位靠这个**）

### 3.2 只读视频，不加识别

- [ ] 装 `opencv-python`
- [ ] 掌握 `VideoCapture`：逐帧读取、结束判断、窗口退出、释放资源
- [ ] 先做到"能逐帧显示并正常结束"，**这一步不要急着加识别**

### 3.3 接预训练模型

- [ ] 装 `ultralytics`（会连带安装 PyTorch，体积较大，建议留出时间）
- [ ] CPU 跑短录像：

```bash
cd /d/Projects/station-device
./.venv/Scripts/yolo.exe predict model=yolo11n.pt source="inputs/test.mp4" classes=0 device=cpu save=True
```

  - `classes=0` 只保留 person（COCO 预训练模型）
  - 首次运行需联网下载官方权重
  - 先检查保存的标注结果，**不要求实时**

- [ ] Python 读取结果、统计本帧人数、写入 CSV，字段至少：

```text
video_id, frame_id, video_time_s, people_visible
```

- [ ] 记住一条规则：**录像时间与电脑处理一帧的耗时是两回事**。记录人数变化用视频时间，处理耗时另存，前者不能拿后者的时间戳代替。

### 3.4 误差检查（实施计划第 9 节，你在首版要负责的"基本精度检查"）

- [ ] 从录像里抽 **100–200 帧**，人工数人，与算法结果逐帧对照
- [ ] 计算每帧绝对误差的平均值（MAE），分别统计偏多、偏少
- [ ] 按场景记录失败案例（遮挡 / 逆光 / 远处太小 / 观察区域划错）
- [ ] 结论按实际观察范围解释：**统计的是"画面内可见人数"**，被完全遮挡或画面外的人，单视角录像无法恢复

### 3.5 可选，等导师明确要求再做

- [ ] ROI 区域计数：先画一个矩形，只统计该区域内的人
- [ ] ByteTrack 与进出计数：需要处理折返、停留、重复计数，**不要在第 1、2 周就开始**
